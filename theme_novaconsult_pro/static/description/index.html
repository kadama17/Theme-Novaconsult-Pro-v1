Installation

  1. Install the module NovaConsult Pro Theme.
  2. Go to Website → Configuration → Settings and select the theme.
  3. Open the demo pages (Homepage, Services, Pricing, Method, Projects, Contact).
  4. Use Website Builder to replace content and images (drag & drop).
Tip: keep your custom sections inside #wrap and rely on scoped theme classes to avoid conflicts.
